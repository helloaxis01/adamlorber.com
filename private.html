Promote a page to Selected Work

  1. Add a work-grid card + sitemap footer link on index.html (and About footer if needed).
  2. Add the pretty URL to sitemap.xml; remove it from robots.txt Disallow.
  3. Remove noindex from the page <head> if present.
  4. Add or refresh a case thumbnail + hero stack card if it should appear in the deck.
  5. Delete the entry here and in HIDDEN-PAGES.txt.

Your launch steps

  • Soak on adamlorber.netlify.app, then point DNS from Squarespace/GoDaddy → Netlify
  • Confirm SSL / HTTPS on custom domain
  • Search Console: verify site + submit sitemap.xml (paste token into AL_GSC_VERIFICATION)
  • Optional: paste GA4 ID into AL_GA4_MEASUREMENT_ID
  • Cancel Squarespace after DNS is stable
